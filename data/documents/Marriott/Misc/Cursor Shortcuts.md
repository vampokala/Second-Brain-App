
## Shortcuts to find all functions in a Python file

### 1. Go to Symbol in File (quickest)

- Mac: Cmd + Shift + O

- Windows/Linux: Ctrl + Shift + O

- Opens a searchable list of functions, classes, and methods in the current file

- Type to filter; press Enter to jump

### 2. Go to Symbol in Workspace

- Mac: Cmd + T

- Windows/Linux: Ctrl + T

- Searches across all files in the workspace

- Type @ to filter to symbols only

### 3. Outline view

- Open the Explorer sidebar (Cmd + B / Ctrl + B)

- The Outline section shows all symbols in the current file

- Click any function to jump to it

### 4. Command Palette

- Mac: Cmd + Shift + P

- Windows/Linux: Ctrl + Shift + P

- Type "Go to Symbol in File" or "Go to Symbol in Editor"

### Tips

- In the symbol picker (Cmd + Shift + O), type : to group by type (functions, classes, etc.)

- Use Cmd + Shift + O then type a function name to filter quickly

- The Outline view updates as you navigate between files

Most common: Cmd + Shift + O (Mac) or Ctrl + Shift + O (Windows/Linux) to see all functions in the current file.
